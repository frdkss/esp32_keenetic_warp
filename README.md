
# esp32_keenetic_warp

## Использование

### 1. Установка

Если у вас не установлен WARP на роутер, можете прочитать как это сделать здесь:

[![Генератор WARP](https://img.shields.io/badge/Генератор-WARP-0099FF?style=for-the-badge&logo=github&logoColor=white)](https://github.com/ImMALWARE/bash-warp-generator)

> [!IMPORTANT]
> *используйте AmneziaWG*

[![Инструкция Amnezia](https://img.shields.io/badge/Инструкция-AmneziaWG-6C5CE7?style=for-the-badge&logo=readthedocs&logoColor=white)](https://docs.amnezia.org/ru/documentation/instructions/keenetic-os-awg/)

**Установите исходный код**

[![Скачать](https://img.shields.io/badge/Скачать-ZIP-2ea44f?style=for-the-badge&logo=github&logoColor=white)](https://github.com/frdkss/esp32_keenetic_warp/archive/refs/heads/main.zip)

#### Требуется:

- Windows 10 или выше
- Роутер Keenetic/Netcraze с версией KeeneticOS 5.1.x и новее
- Наличие Wireguard туннеля

---

### 2. Запуск программы

1. Подключите вашу **ESP32** к компьютеру.
2. Распакуйте архив в удобную для вас папку, затем откройте распакованный архив.
3. Нажмите ПКМ по `service.ps1` и нажмите `Выполнить с помощю PowerShell`.
4. Затем будут запрошены права администратора, нажмите `Да`.

### 3. Установка зависимостей

1. Затем введите `1` и нажмите `Enter` для того чтобы установить зависимости.
2. После установок зависимостей нажмите `Enter` чтобы вернуться в главное меню.

---

### 4. Настройка роутера для ESP32

#### 4.1. Создание пользователя для ESP32

1. Перейдите на Web интерфейс вашего роутера Keenetic/Netcraze, например `192.168.1.1`.
2. Войдите в аккаунт.
3. Перейдите во вкладку **Управление** → **Пользователи и доступ** и нажмите на кнопку `Добавить пользователя`.
4. Задайте для него **имя** и **надёжный пароль**, затем дайте ему доступ к сервису **«Веб-конфигуратор»**, после чего сохраните.

#### 4.2. Настройка HTTPS домена

1. Перейдите на Web интерфейс вашего роутера Keenetic/Netcraze, например `192.168.1.1`.
2. Войдите в аккаунт.
3. Перейдите во вкладку **Сетевые правила** → **Доменное имя**.
4. Задайте доменное имя, режим работы `Авто`, и выберите пункт `Не использовать IPv6`.

> [!NOTE]
> Доступ из интернета не обязателен.

---

### 5. Настройка config устройства

В главном меню введите `2` и нажмите `Enter`.

#### 5.1. Логин и пароль — пункт `1`

Выберите пункт `1` и задайте Логин и пароль в соответствующие поля.

Затем, если всё было введено верно:

1. Нажмите `1` для подтверждения.
2. Нажмите `0` для возврата в меню настройки config.

#### 5.2. Модули — пункт `2`

Выберите пункт `2` для того чтобы включить или отключить модули, например `Дисплей`.

#### 5.3. Порт устройства — пункт `3`

Выберите пункт `3` для того чтобы выбрать порт на котором находится ваша плата.

1. Выберите её номер.
2. Нажмите `0` для возврата в меню настройки config.

> [!TIP]
> *если плату не видно, попробуйте обновить список либо попробовать другой порт USB и обновить список*

#### 5.4. Настройки контролера — пункт `4`

Выберите пункт `4` для настройки работы вашего контролера.

**Управление:**

| Действие | Клавиша |
|---|:---:|
| Чтобы выбрать пункт | `Enter` |
| Чтобы подтвердить изменения | `Enter` |
| Чтобы отменить изменения | `Esc` |

> [!NOTE]
> **В некоторых пунктах требуется управление стрелками**

---

##### Проверяемые домены

| Параметр | Описание | Пример |
|---|---|---|
| **Домены проверки WARP** | Вводятся домены сайтов которые будут стабильно работать с WARP (желательно добавить несколько) | `youtube.com`, `soundcloud.com`, `instagram.com`, `x.com` |
| **Домены проверки NETWORK** | Вводятся домены для проверки сайтов которые будут работать даже если WARP выключен | `yandex.ru`, `ozon.ru`, `avito.ru` |

##### Интервалы и таймауты

| Параметр | Описание | Пример |
|---|---|:---:|
| **Интервал циклов** | Вводится значение интервала циклов между проверками сайта значения вводятся в секундах | `60` |
| **Таймаут соединения** | Вводится значение сколько ждать установления соединения при проверке, от 1 секунды до 60 секунд | `5` |
| **Таймаут чтения** | Вводится значение сколько ждать ответа при проверке сети, от 1 до 60 секунд | `5` |

##### Обнаружение сбоев WARP

| Параметр | Описание | Пример / значение |
|---|---|---|
| **Подтверждение сбоя** | Вводится значение сколько подряд неудачных подключений необходимо перед попыткой восстановления WARP (от 1 до 1000 раз) | `5` |
| **Порог целевых отказов** | Устанавливается значение доли нерабочих сайтов из пункта `Домены проверки WARP` | **Больше половины** |

**Доступные значения порога целевых отказов:**

| Значение |
|---|
| `Любой нерабочий` |
| `Половина` |
| `Больше половины` |
| `Все` |

> По умолчанию: **Больше половины**

##### Восстановление WARP

| Параметр | Описание | Пример / по умолчанию |
|---|---|:---:|
| **Ожидание включения** | Вводится значение сколько ждать после включения WARP прежде чем проверять результат восстановления, от 1 до 3600 секунд | `30` |
| **Пауза между попытками восстановления** | Устанавливается значение паузы после завершения попытки перед следующей возможной попыткой, от 5 минут до 30, с шагом в 5 минут | **5 минут** |
| **Пауза включения/выключения** | Вводится значение сколько держать WARP конфиг перед обратным включением при восстановлении от 1 до 3600 секунд | `2` |
| **Автоматическое восстановление** | Устанавливается значение `Вкл`/`Выкл`, разрешает включение и выключение WARP после подтвержденного сбоя | **Вкл** |

##### Расписание и часовой пояс

| Параметр | Описание | Пример / по умолчанию |
|---|---|---|
| **Плановый перезапуск** | Устанавливается 3 значения `Вкл`/`Выкл`, день недели, часы, минуты | `Вкл` / `Четверг` / `05:00` |
| **Часовой пояс (POSIX)** | Выбирается часовой поиск | `MSK-3` |

##### Подключение к Keenetic

| Параметр | Описание | Пример / по умолчанию |
|---|---|---|
| **Адрес Keenetic** | Вводится IP адрес вашего роутера | `192.168.1.1` |
| **HTTPS-Имя** | Вводится настроенный HTTPS Домен | `KN-4010.netcraze.link` |
| **HTTPS-Порт** | Вводится HTTPS порт посмотреть можно во вкладке **Пользователи и доступ** в разделе **Службы управления** в пункте **Порт управления по HTTPS** | `443` |
| **Интерфейс WARP** | С роутера собираются все ваши Wireguard интерфейсы, затем вами устанавливается значение вашего Wireguard интерфейса | `Wireguard1` |

После настройки введите `0` для возврата в меню настройки config.

---

#### 5.5. Подключение к Wi-Fi — пункт `5`

Выберите пункт `5` для того чтобы ввести параметры подключения к сети.

1. Введите `SSID` (имя вашей WiFi сети).
2. Затем `Password` для ввода пароля от вашего WiFi.
3. Если все верно введите `1` для подтверждения.
4. Затем введите `0` для возврата в меню настройки config.

#### 5.6. Проверка конфигурации

Введите `0` для возврата в главное меню.

Теперь в статусах у вас будет записано:

| Параметр | Статус |
|---|---|
| **Порт** | *ваш выбранный порт* |
| **CFG** | **заполнен** |
| **Ключи** | **не созданы** |

> [!WARNING]
> если **CFG** в статусе **не заполнен**, проверьте заполнение и попробуйте еще раз, все заполнено, попробуйте перезапустить программу

---

### 6. Создание ключа устройства

Убедитесь что устройство подключено, затем нажмите `3`.

1. Введите папку для ключа.
2. Затем создадутся ключи защиты.
3. Придумайте пароль для защиты ключа и сохраните его в надёжном месте.

> [!IMPORTANT]
> Ключ нужен для того чтобы зашифровать память ESP32, сохраненные настройки (логины и пароли), а также подпись прошивки secure boot чтобы прошивку нельзя было подменить.

---

### 7. Загрузка прошивки на микроконтроллер

После успешной настройки config и создания ключа выберите пункт `4` и дождитесь установки прошивки на ваш микроконтроллер.
