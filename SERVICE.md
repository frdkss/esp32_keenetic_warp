# Настройка Keenetic в SERVICE

Запустите `./service.ps1`, откройте **2. Настроить config → 4. Сеть и мониторинг**.

- Укажите LAN IPv4-адрес Keenetic и HTTPS-порт (обычно `443`). HTTPS-имя загружается с роутера автоматически при входе в этот экран и после изменения адреса или порта. Имя сохраняется в CFG после проверки HTTPS-сертификата. Для повторного получения нажмите `R` или Enter на строке HTTPS-имени.
- На строке **Интерфейс WARP** нажмите Enter. SERVICE прочитает существующие WireGuard-интерфейсы Keenetic и покажет их идентификаторы (`Wireguard0`, `Wireguard1` и т. д.), описания и состояние. Выберите нужный стрелками и нажмите Enter для сохранения. Esc отменяет выбор; `0` возвращает назад, `00` завершает SERVICE.
- Для получения списка интерфейсов нужны логин и пароль Keenetic из **CFG → 1. Логин и пароль**. Сначала установите зависимости через пункт 1 главного меню.

Имя определяется по HTTP-перенаправлению самого роутера. Данные входа передаются только по HTTPS с проверенным сертификатом; конфигурация роутера при чтении списка не меняется. Если имя получить или проверить не удалось, SERVICE показывает причину. При смене IP старое HTTPS-имя и выбор WARP сбрасываются; при смене HTTPS-порта обновляется имя, а выбор WARP сохраняется.

Изменения сохраняются в зашифрованном CFG на компьютере. На микроконтроллер они попадают при загрузке прошивки с этими параметрами через пункт 4 главного меню.
